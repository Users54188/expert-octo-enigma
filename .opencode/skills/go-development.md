## Go 开发规范

- 使用 Go 1.21+ 特性
- 遵循 Go 代码规范和最佳实践
- 正确处理错误（不要 panic）
- 使用 context 进行超时和取消控制
- 编写可测试的代码
- 使用 `go fmt` 和 `go vet` 进行代码格式化

## 开发流程

1. 分析需求和设计
2. 编写代码实现
3. 编写单元测试
4. 运行测试验证
5. 代码审查和优化

## 调试

- 使用 `go test -race` 检测竞态条件
- 使用 `pprof` 进行性能分析
- 使用 `-bench` 进行基准测试
