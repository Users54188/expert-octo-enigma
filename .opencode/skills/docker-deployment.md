## Docker 最佳实践

- 使用多阶段构建
- 最小化层数
- 使用 `.dockerignore`
- 非 root 用户运行
- 健康检查
- 资源限制

## 部署流程

1. 分析应用需求
2. 编写 Dockerfile
3. 优化镜像大小
4. 配置环境变量
5. 设置健康检查
6. 构建镜像
7. 测试容器

## 常用命令

- `docker build`
- `docker run`
- `docker-compose up`
- `docker-compose down`
- `docker logs`
- `docker exec`
